# Instalacja

Żeby pracować nad naszym projektem, instalujemy trzy darmowe programy: .NET SDK, Visual Studio Community i Git.

## .NET SDK

https://dotnet.microsoft.com/download

.NET SDK to zestaw narzędzi do budowania i uruchamiania programów w C#, a pobieramy najnowszą wersję oznaczoną jako LTS (z długim wsparciem).

## Visual Studio Community

https://visualstudio.microsoft.com/vs/community/

To darmowy program do pisania i uruchamiania kodu w C#, a przy instalacji zaznaczamy pakiet „ASP.NET and web development” (w polskim instalatorze ten z „ASP.NET” w nazwie).

## Git

https://git-scm.com/downloads

Git zapamiętuje kolejne wersje naszych plików i wysyła je na GitHuba, a przy instalacji wystarczy zostawić domyślne ustawienia i klikać „Next”.
